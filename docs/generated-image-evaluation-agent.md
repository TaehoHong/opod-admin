# 생성 이미지 평가 Agent

Status: 구현 완료 (2026-08-11)

## 목적

프롬프트의 문장 품질이 아니라 실제 생성된 픽셀을 심사한다. 각 후보를 기획,
촬영 방식, 인물 레퍼런스, 공간 레퍼런스와 대조하고 후보별 통과·반려 사유를
검수 화면에 노출한다. 평가는 비동기·비차단이며 자동 재생성이나 자동 게시
결정은 하지 않는다.

## 평가 시점과 입력

`DRAFT_READY_FOR_REVIEW` action 이후 컷별 최신 completed job과 모든 후보를
클레임한다. 입력은 다음과 같다.

- 기획의 `scene`, `captureSetup`, 최종 이미지 프롬프트
- `_shot.identityReferenceMediaIds`, `_shot.environmentReferenceMediaIds`
- `GenerationJobOutput`의 실제 후보 이미지

S3 객체는 `createMediaBytesReader`로 읽어 base64 이미지로 비전 LLM에 전달한다.
평가한 `jobId`와 `mediaId`는 `DraftEvaluation.scoresJson`에 고정 기록한다.

## 엄격한 판정

차원은 기획·촬영 충실도, 정체성 보존, 의상·공간 일관성, 사진 현실감,
생성 결함이다. 다음 결함은 하드 실패다.

- 얼굴 노출, 크롭, 포즈, 휴대폰 방향 불일치
- 의상 구조 변경, 인물·신체 비율 드리프트, 공간 변경
- 손·반사 물리 오류, 심각한 AI 결함, 컷 간 연속성 붕괴

하드 실패가 있거나 한 차원이라도 1~2점이면 후보는 반려된다. 하드 실패 후보와
모든 후보가 반려된 게시물의 총점은 평균이 높아도 2.99 이하로 제한한다.

## 검수 화면

후보 카드에는 7개 차원 점수, 통과·반려 배지, 펼쳐 보는 하드 실패를 표시한다.
게시물 단위에는 선택 가능한 후보 조합의 컷 간 일관성 점수와 하드 실패를
표시한다. 운영자는 이 근거를 보고 후보를 선택하거나 컷을 재생성한다.
