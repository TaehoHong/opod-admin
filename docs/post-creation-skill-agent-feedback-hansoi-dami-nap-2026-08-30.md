## 부정 평가와 수정 결과

- 집 레퍼런스 반영 여부가 불분명했다. 변경된 원룸 레퍼런스를 다시 확인하고 방의 침대·창틀·캣타워 위치가 식별되도록 재생성했다.
- 3번이 앉아 있는 것처럼 보이거나 누운 자세의 머리카락·얼굴·의상 주름이 부자연스러웠다. 머리와 어깨를 베개 평면에 두고 접촉 압력과 그림자를 보강했다.
- 여름 게시물에 니트가 더워 보였다. 두 인물 컷의 의상을 얇은 반소매 코튼 티셔츠로 통일했다.
- 팔이 길고 평행하게 보여 해부학적으로 어색했다. 셀카 원근과 반대 팔의 굽힘·손 연결을 분리했다.
- 담이와 소이의 시선이 요구와 달랐다. 담이→소이, 소이→카메라 관계를 명시적으로 잠갔다.
- `글래머러스 톤`으로 재해석한 응답은 사용자의 구체적인 신체 비율 수정 의도와 달랐다. 이후에는 모호한 분위기 표현으로 바꾸지 않고 요청된 시각 필드를 직접 수정했다.
- 얼굴 레퍼런스 일치가 약했다. 누운 각도에서도 눈매·코·얼굴형·턱선의 우선순위를 높여 재생성했다.

## 최종 승인 기준

- 한소이 얼굴이 공식 얼굴 레퍼런스와 일치한다.
- 변경된 연남동 원룸의 공간 구조가 1번과 3번 사이에서 이어진다.
- 3번에서 소이는 카메라를, 담이는 소이를 본다.
- 담이는 오른쪽으로 누운 채 목만 자연스럽게 돌린다.
- 두 컷의 의상은 같은 늦여름용 아이보리 반소매 티셔츠다.
- 누운 머리카락, 얼굴 접촉, 팔, 옷과 침구 주름이 물리적으로 자연스럽다.
- 최종 게시에는 1번과 3번만 포함한다.

## Skill 반영 후보 규칙

1. 사용자가 `레퍼런스와 같은지 비교`라고 하면 생성 프롬프트 수정 전에 얼굴·공간·의상·포즈를 항목별로 대조하고 불일치 필드만 재생성한다.
2. 공간 레퍼런스가 교체되면 변경 전 공간을 사용한 모든 활성 후보를 자동 무효화하고, 정면·역방향·세로 뷰로 공간 연속성을 검수한다.
3. 누운 셀카는 베개 접촉, 머리카락 중력, 얼굴 압력, 셀카 팔 원근, 반대 팔 연결, 옷·침구 주름을 독립 검수 필드로 둔다.
4. 계절 의상 수정 뒤에는 같은 캐러셀의 인물 컷 전체에서 의상 연속성을 다시 확인한다.
5. `글래머`처럼 사용자가 신체 비율을 명시한 요청을 분위기·톤으로 재해석하지 않는다. 대상 신체 필드, 적용 컷, 노출 제한과 원단 물리를 그대로 잠근다.
6. 동물의 목 회전 자세는 몸통의 접지 방향과 목 각도를 분리해 검수하고, 허용 가능한 해부학 범위인지 먼저 판단한다.
7. 최종 선택 문장 `1,3번만 게시`는 기존 선택을 덮어쓰며 업로드 폴더와 파일명에 순서 접두사를 붙여 정확한 파일만 선택한다.

## Work 상태·행동 개선 후보

- 사용자 정정이 나오면 앞선 지시를 `superseded`로 남기고 활성 지시만 생성 프롬프트와 게시 manifest에 전달한다.
- 이미지 하나를 바꿔도 전체 캐러셀의 공간·의상·색감 연속성을 다시 검수한다.
- Admin 업로드 전 캐릭터, 형식, 캡션, 해시태그, 파일명과 개수·순서를 한 화면에서 대조한다.
- 한글이 일반 키 입력으로 누락될 수 있으므로 settable 입력란의 최종 Value와 생성된 태그 칩을 화면에서 확인한다.
- iCloud 암호 활성화 팝업은 게시와 무관한 인증 확장 UI이므로 입력하거나 활성화하지 않고 닫는다.

## 회귀 평가 시나리오

1. 원룸 레퍼런스 교체 뒤 기존 공간 후보가 활성 상태로 남지 않는지 검사한다.
2. `3번만 재생성`에서 1번의 픽셀·의상·구도가 바뀌지 않는지 검사한다.
3. 누운 셀카에서 머리·어깨가 침대 평면에 있고 셀카 팔과 반대 팔이 해부학적으로 연결되는지 검사한다.
4. 담이 몸통은 오른쪽 측와위를 유지하면서 목만 45~60도 회전하고 소이를 보는지 검사한다.
5. 소이는 카메라를, 담이는 소이를 보는 두 시선 조건을 동시에 검사한다.
6. 여름 의상 변경이 활성 인물 컷 전체에 일관되게 적용되는지 검사한다.
7. 얼굴 레퍼런스 일치 검수 후 눈매·코·얼굴형·턱선 네 항목이 모두 유지되는지 검사한다.
8. `1,3번만 게시` 뒤 Admin 게시 상세에 미디어가 정확히 2개이고 순서가 1→3인지 검사한다.
9. 캡션과 해시태그 승인 뒤 Admin 상세 문자열이 `담이 따라 누운 오후.`와 `#담이 #늦여름`인지 검사한다.

## 게시·업로드 이슈

- 화면 오류 원문: `ERR_BLOCKED_BY_CLIENT` — Naver Whale에서 Admin 접근이 차단되어 로그인된 Google Chrome 탭으로 전환했다.
- 화면 오류 원문: `암호 자동 완성 활성화` — Chrome의 iCloud 암호 확장 팝업이 나타났다. 원인은 인증 코드 입력 없이 확인할 수 없으므로 `게시와 무관한 확장 UI`라는 관찰만 확정하고, 팝업을 닫아 게시를 계속했다.
- 화면 오류 원문: `Timed out waiting for the application to read the clipboard` — 해시태그 붙여넣기 중 발생했다. 클립보드 읽기 타임아웃은 확인됐지만 원인은 확정하지 않았다. settable 값으로 입력한 뒤 태그 칩과 Admin 상세의 `# 담이 # 늦여름`을 확인했다.
- 파일 선택 창에서 목록 포커스 전 전체 선택 단축키가 적용되지 않았다. 키보드로 첫 항목을 선택한 뒤 `Shift+Down`으로 두 항목을 범위 선택해 해결했다.
- 게시 후 목록 최상단과 상세 `/publish` 화면에서 게시 완료, 게시물 ID, 캡션, 해시태그, 미디어 2개를 확인했다.
