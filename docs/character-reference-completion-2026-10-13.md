# 전체 캐릭터 레퍼런스 재판정·추가 보정 — 2026-10-13

사용자가 “다른 캐릭터들은 왜 수정 안해?”, “다시 판단해서 수정해”라고 요청해, 나희·해나의 전신 4장에 한정했던 교체 범위를 다시 판단했다. 활성 레퍼런스 35장 모두를 검토 대상으로 삼았다. 체격 수정이 필요한 사진과 조명 수정이 필요한 사진을 함께 선정했다.

## 현재 결과

기존 나희 20·30, 해나 40·60의 교체 완료본은 유지한다. 추가 21장은 이미지 생성과 직접 검수를 완료했고, 개발 서버 반영은 승인 대기다. 서린의 스포츠브라 사진 9장은 상의 변경 선택을 기다린다. 서린 120은 실제 복도 주변광이 있는 보조 자료이므로 유지한다.

원본과 새 출력 이미지를 직접 보고 캐릭터별 비교판으로 다시 대조했다. 얼굴·헤어·식별 특징, 전신 실루엣, 팔·관절의 연결, 표정·각도별 일관성, 크롭과 참조 역할, 배경·인물의 밝기 관계를 검토했다. 한소이·유하의 조정은 시각적 비율 판정이며 실측한 등신이나 길이의 수치 보정은 아니다. 서린의 얼굴과 머리가 가려진 자료로는 머리 비율을 확정하지 않는다.

조명 보정은 사진을 단순히 어둡게 하는 대신 정면 하이라이트와 피부 광택을 낮추고 확산광의 완만한 음영과 질감을 남기는 방향으로 진행했다. 새 참조 설명에는 얼굴·체형과 별도로 현재 장면의 광원 방향·색온도·노출·접지 그림자를 배경에 맞추도록 기록했다. 새 레퍼런스 자체의 검수 통과와 향후 SNS 결과의 조명 통합 검증은 구분한다. 장소·시간별 생성 비교 시험은 아직 실행하지 않았다.

## 서린의 보류 사유

스포츠브라가 있는 서린 10의 조명 보정 요청은 이미지 생성기의 출력 필터에 두 차례 차단됐다. 다른 스포츠브라 8장도 차단됐다고 확인한 것은 아니다. 기존 회색 티셔츠 사진 130의 보정은 성공했다. 얼굴 비공개와 체형을 유지하면서 나머지 9장을 회색 운동 티셔츠로 바꿀지, 스포츠브라를 유지하고 그 9장을 보류할지 사용자 선택을 요청했다. 답변 전에는 해당 9장의 의상을 변경하거나 대체 사진을 등록하지 않는다.

## 개발 서버 교체 상태

추가 21장의 보정본은 `character-assets/{캐릭터}/references/reference-correction-20261013/`에 저장했다. 기존 `MediaService.startUpload/confirmUpload`, `VisualProfileService.setReferences/updateReferenceDescription/saveReferenceEmbedding`을 사용하는 등록 스크립트와 새 참조 설명을 준비했다. 직접 SQL이나 앱 코드 변경은 없다.

추가 업로드 시도는 자동 승인 검토가 실행 전에 거절했다. 사유는 이전의 명시적 서버 전송 승인이 4장에 한정돼, 추가 21장과 참조 메타데이터 전송을 포함하지 않는다는 것이다. 121.141.156.200:300 개발 서버와 dev-opod-public 목적지로 추가 자료를 전송하고 교체하는 승인을 요청했다. 아직 추가 21장을 전송하거나 활성 레퍼런스를 교체하지 않았다.

승인 후 기존 원본을 비활성 이력으로 보존하고 새 21장만 활성화한다. 각 사진의 설명과 검색 임베딩을 갱신한 뒤 새 활성 목록·상대 순서·파일 SHA-256·설명 및 색인 상태, Canon·프로필 프롬프트, 유지한 사진의 내용을 재조회해 확인한다. 현재 활성 35장과 앞서 교체한 4장의 상태는 그대로다.
