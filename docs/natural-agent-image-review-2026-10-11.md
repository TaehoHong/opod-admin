# 새 Agent(natural-v1) 생성 이미지 리뷰 — 2026-10-11

평가 기준은 [게시물 이미지 평가 기준](image-evaluation-criteria.md)을 따른다.
대상 Agent의 설계는 [자연스러운 사진 자동 제작 Agent](natural-post-agent.md)에 있다.
이 문서는 개발 서버에서 실제로 생성·게시된 이미지에 대한 사람의 리뷰 기록이며,
프롬프트나 루브릭을 바꾸지 않았다.

## 1. 평가 대상과 확인한 자료

- 대상: 개발 서버 `postGenerationAgent=natural-v1` 초안 7건 전부(2026-10-08 배치).
  6건 게시, 1건(서린 원 초안 `01a119c7-196d…`)은 두 컷 모두 이미지 API HTTP 400으로 실패 후
  인물 없는 장면의 새 초안으로 교체됐다.
- 실행 설정: 설정 revision `sha256:156f226e…`(2026-10-08 03:43 UTC 저장, 2026-10-11 현재도 동일).
  기획·검수 모델 `gpt-5.6-terra`, 이미지 `gpt-image-2.5-sunburst`, 전 컷 `route=edit`.
  저장된 단계 지침은 커밋 `92ee01e`의 starter와 같은 짧은 버전이다. 작업 트리의
  수정된 starter(`prompts/natural-post-agent.ts`, 미커밋)는 이 배치에 쓰이지 않았다.
- 확인한 이미지: 생성 10장 원본(1024×1280, 최초 생성 7 + 운영자 재생성 3), 배정된 레퍼런스 원본 19장,
  같은 날 같은 캐릭터로 돌린 기존 Agent(V4) 결과 5장. 얼굴·손·소품은 원본 해상도로 확대 확인했다.
- 함께 확인한 기록: 컷별 최종 프롬프트, 레퍼런스 바인딩, 두 검수의 관찰·판정, 재생성 보정 문구.
- 확인하지 않은 것: 실제 SNS 사진과의 대조, 동일 조건 반복 생성(변동성), 캡션 품질.

## 2. "사람이 찍은 듯한 자연스러운 사진"의 판단 신호

기준 문서의 목표("실제 개인 SNS에 섞였을 때 사람이 그 상황에서 찍은 사진처럼 보이는가")와
관점 표를 그대로 쓰고, 이번 리뷰에서 실제로 판정을 가른 신호만 구체화한다.
카메라 응시·포즈·연출 자체는 실패 근거가 아니다(기준 §3).

| 관점 | 자연스러운 신호 | 인공적인 신호(이번 배치에서 관찰된 것 위주) |
| --- | --- | --- |
| 촬영 주체 | 누가 어디서 찍었는지 이미지 안에서 성립한다. 거울 사진이면 기기가 반사 안에 있다. | 거울 속에 기기가 없음, 기기가 엉뚱한 방향, 기획한 촬영 장치와 다른 시점 높이 |
| 시선 | 시선에 대상이 있고 행동·관계와 맞는다. 피드 전체로 보면 응시·외면·셀피가 섞인다. | 보이는 얼굴이 모두 아래·옆을 보는 동일 패턴 |
| 표정 | 장면의 감정에서 나온 표정. 무표정, 크게 웃는 입, 집중한 얼굴이 모두 가능하다. | 레퍼런스의 다문 입 미소가 장면과 무관하게 남음 |
| 자세·행동 | 무게·접촉·몸의 방향이 하는 일과 맞는다. | 정지 포즈에 덧댄 설명용 손동작, 가구 방향과 무관하게 카메라를 향한 몸 |
| 구도 | 촬영 의도에 맞는 프레이밍. 생활 속 촬영이면 약간의 비대칭·잘림이 자연스럽다. | 레퍼런스와 같은 시점·소실점, 모든 컷이 정돈된 화보 구도 |
| 빛·질감 | 하나의 공간의 빛, 공간에 맞는 질감. | 쇼룸·화보 같은 일률적 이상화(얼굴·방·소품 전부) |
| 레퍼런스 과적합 | 정체성만 유지되고 표정·포즈·구도·조명은 바뀐다. | 표정 잔존(유하), 장소 구도 복제(서린), 장소 레퍼런스의 부수 소품 반복(도건) |
| 컷 연속성 | 같은 공간의 컷은 바닥·가구·문·소품이 이어진다. | 같은 현관이라던 두 컷의 타일·신발장·문이 다름(해나) |
| 소품 | 사건에 필요한 소수의 물건과 우연한 생활 흔적. | 기획이 지정한 서사 소품이 진열처럼 놓임(나희, 서린) |

## 3. 컷별 판정

판정은 기준 문서 §4의 합격/불합격만 쓰고 점수를 붙이지 않는다.

| 게시물 | 자연스러움 | 기획·스타일 | 정체성 | 연속성 | 전체 |
| --- | --- | --- | --- | --- | --- |
| 해나 (2컷) | 1컷 합격(정돈감 강함), 2컷 합격 | 합격 | 합격 | **불합격** | **불합격** |
| 유하 | **불합격** | 합격(기획 자체가 문제) | 합격, 표정 잔존 | 해당 없음 | **불합격** |
| 나희 (재생성본) | **불합격** | 합격 | 합격 | 해당 없음 | **불합격** |
| 권도건 (재생성본) | 합격(상업 사진 인상) | 합격 | 합격 | 해당 없음 | 합격 |
| 한소이 (재생성본) | 합격(연출된 라이프스타일 인상) | 시점 높이 경미한 불일치 | 해당 범위 합격 | 해당 없음 | 합격 |
| 서린 | 합격 | **불합격** | 해당 없음, 장소 구도 복제 | 해당 없음 | **불합격** |

게시된 6건 중 2건 합격. 6건 모두 두 검수를 accept로 통과해 자동 게시됐다.

### 해나 — 현관에서 운동화 끈 묶기 (2컷)

- 1컷: 무릎 꿇은 자세·체중·손과 끈의 접촉이 성립하고 시선도 손끝에 있다. 얼굴·현관이
  모두 깨끗하게 이상화돼 화보 인상이 있으나 실제 사진으로 성립한다.
- 2컷: 바닥 높이 폰 시점, 문틈 빛과 타일 반사, 광각 원근이 실제 폰 사진에 가장 가깝다.
- 연속성 불합격: 1컷은 밝은 회색 대형 타일·오른쪽 흰 유광 신발장·회색 문, 2컷은 어두운
  소형 타일·왼쪽 원목 신발장·검은 문이다. 가방 위치와 운동화 모델도 다르다.
  두 컷 모두 문을 향해 찍었으므로 신발장이 좌우로 바뀔 수 없다.
- 검수: requirements가 "동일한 현관 타일, 문틈 빛, 신발장과 크로스백이 이어져"라고 썼다. 사실과 다르다.
- 확인된 원인: `locationSelected`가 비었고 두 컷의 레퍼런스는 인물 정체성뿐이다.
  같은 현관은 텍스트로만 전달됐고 컷은 서로를 보지 못한 채 따로 생성됐다(기준 §5의 경고 그대로).

### 유하 — 카페 창가, 치마 트임 정리

- 자연스러움 불합격: 정지된 패션 포즈 위에 "트임 가장자리를 집는" 손동작이 얹혀 있다.
  눈을 거의 감은 하향 시선과 다문 입 미소가 함께 나와 설명용 동작으로 읽힌다.
  의자는 테이블 쪽을 보는데 몸 전체는 카메라를 향해 옆으로 앉아 있다. 얼굴·피부·카페가
  일률적으로 이상화돼 룩북 촬영 인상이다. 패션 연출 자체를 실패로 본 것은 아니다.
- 레퍼런스: 세 레퍼런스가 모두 다문 입 미소이고, 프롬프트가 "미소 표정의 복제"를 피하라고
  했는데도 같은 미소가 남았다(관찰). edit 경로의 얼굴 레퍼런스 영향은 가설이다.
- 기획: 손동작은 이미지 기획이 직접 지시했다. 캡션도 그 트임을 말한다. 생성 문제가 아니라 기획 문제다.
- 검수: naturalness가 이 손동작이 하향 시선과 "자연스럽게 연결된다"고 통과시켰다.

### 나희 — 거울 앞 코디 비교 (재생성)

- 재생성 전: 거울 사진인데 반사 안에 기기·촬영자가 없다. naturalness가 정확히 불합격 처리했다.
- 재생성 후(게시): 거울 밖 서랍장 위에 스탠드에 꽂힌 폰이 추가됐지만 렌즈가 보는 사람 쪽을
  향하고, 거울 속에는 여전히 폰도 서랍장도 비치지 않는다. 어떤 해석으로도 이 폰은 이 사진을
  찍은 기기가 될 수 없다. 결함을 고친 것이 아니라 소품으로 덮었다.
- 그 밖: 침대 위 니트, 벤치 위 가방·로퍼는 기획이 지정한 소품이고 진열처럼 놓였다.
- 검수: naturalness가 "폰의 반사된 카메라 각도가 피사체를 담는다"고 통과시켰다. 사실과 다르다.

### 권도건 — 박스 코칭 구역에서 마커 정리 (재생성)

- 표정·시선·손·자세가 한 동작으로 이어지고 피부 질감도 이번 배치에서 가장 사진답다.
  깨끗한 상업 사진 인상이지만 실제 사진으로 성립한다. 누가 찍었는지는 설명되지 않는다.
- 장소 레퍼런스의 바벨 랙·범퍼 플레이트 색 순서·분무기·초록 수건까지 반복됐다. 같은 박스의
  일관성으로 읽힐 수 있어 실패로 보지 않았다.
- 재생성: 재생성 전 이미지도 자연스러움은 같은 수준이었다. 불합격 사유는 "허벅지 위 프레이밍
  미충족"과 헤어 차이였고, 재생성본은 같은 구도를 조금 좁힌 결과다. 자연스러움은 그대로이고 비용만 늘었다.

### 한소이 — 저녁 책상에서 네거티브 정리 (재생성)

- 램프 빛·그림자·필름 슬리브 반사가 일관되고 손과 필름 스트립의 접촉이 정확하다.
  소품 배열이 잘 정돈된 라이프스타일 사진 인상이지만 실제 사진으로 성립한다.
- 기획 불일치(경미): 기획은 낮은 책장 위 AE-1 셀프타이머였지만, 결과는 서 있는 사람 눈높이의
  어깨 너머 시점이다. 혼자 사는 원룸의 밤에 누가 찍었는지가 약해진다. requirements는 통과시켰다.
- 재생성 전 이미지: 책상이 옆에 있는데 몸통은 카메라를 향해 앉았고, 얼굴이 입술에서 잘리는 구도였다.
  불합격 사유는 얼굴 노출·시점이었고 자세 문제는 지적되지 않았지만 결과적으로는 재생성본이 더 자연스럽다.

### 서린 — 운동 나가기 전 현관 (인물 없음)

- 사진 자체는 자연스럽다. 다만 세로선이 완벽히 보정된 부동산 사진 원근이라 폰 스냅으로는 보이지 않는다.
- 레퍼런스 과적합·기획 불합격: 장소 레퍼런스와 시점·소실점·벤치·문·거울 배치가 같다.
  사실상 원본을 4:5로 자르고 소품을 얹은 결과다. 프롬프트는 "원본의 넓은 정면 와이드 구도"를 피하고
  "낮은 사선 스마트폰 시점"으로 찍으라고 했다.
- 검수: requirements가 "레퍼런스의 정면 구도를 단순 복제하지 않았다"고 썼다. 사실과 다르다.
- 별도 문제: 원 초안(스포츠 브라톱 미러 셀피)이 HTTP 400으로 두 번 실패했다. 당시 응답 본문이
  저장되지 않아 원인은 미확인이다(이후 `eedfce3`에서 응답 본문 보존을 추가했다).
  인물 중심 계정에서 인물 없는 컷으로 대체한 것은 대안이 아니라 우회다.

## 4. 배치 전체에서 보이는 패턴

1. **새 템플릿으로의 수렴.** 인물이 나오는 6장이 모두 손으로 작업 중이고, 얼굴이 보이는 4장은
   모두 아래나 옆을 본다. 카메라를 의식한 컷, 셀피, 웃는 얼굴이 하나도 없다. 한 장씩은 성립해도
   피드로 이어 보면 이것 자체가 생성 이미지의 표식이 된다. 기준 §9가 기본 처방으로 쓰지 말라고 한
   "모든 사진을 우연한 순간으로 통일하기"에 해당한다.
2. **검수의 오수용(false accept).** 불합격 4건 중 3건(해나, 나희, 서린)에서 검수가 사실과 다른
   관찰을 근거로 accept했다. 남은 1건(유하)은 지침이 경고한 패턴을 자연스럽다고 판단했다.
   검수는 10장 중 3장을 거절했다. 그중 자연스러움 사유는 1장이고 나머지 2장은 프레이밍·얼굴 노출 같은
   준수 사유였다. 자동 모드에서는 이 검수가 유일한 관문이라 오수용이 그대로 게시로 이어졌다.
3. **재생성이 고치지 않고 덮는다.** 보정 문구는 관찰 전문(긍정 관찰 포함)을 프롬프트 끝에 붙인다.
   생성기는 촬영 설계를 바꾸지 않고 빠진 물건을 추가했다(나희). 세 번의 재생성 모두
   원래 구도를 거의 그대로 다시 냈다.
4. **기획이 연출을 만든다.** 유하의 손동작, 나희·서린의 진열형 소품은 생성기가 아니라 기획 출력에서 왔다.
5. **기존 Agent 대비.** 같은 날 기존 Agent 결과 5장 중 3장(나희 2, 해나 1)은 레퍼런스와 같은 미소로
   카메라를 응시했고, 한소이 컷은 두 손이 모두 바쁜데 AE-1이 화면 안에 있는 성립 불가능한 1인칭 시점에
   브랜드 글자가 읽혔다. 새 Agent는 이 유형(정면 응시 + 레퍼런스 미소, 브랜드 노출)을 줄였다.
   개선이지 합격은 아니다.

## 6. 다음 비교 제안

순서는 자동 게시 위험이 큰 것부터다. 각 비교는 모델·레퍼런스·캐릭터를 고정하고 한 요인만 바꾼다.

1. **검수 보정 세트.** 이번 10장과 기존 Agent 5장에 사람 판정(이 문서)을 붙여 고정 세트로 만들고,
   검수의 컷별 정확도를 잰다. 이후 검수 변경은 이 세트의 오수용 감소로만 개선으로 인정한다.
2. **검수의 구조화된 대조.** 서술 전에 사실 항목을 먼저 적게 한다. 여러 컷은 컷별 바닥·가구·문·조명·소품
   표를 만들고 대조한다. 장소 레퍼런스는 시점 높이·방향·소실점을 비교한다. 거울·셀프타이머는 기기의 위치와
   방향이 반사와 맞는지 확인한다. 기획과 다른 검수 모델도 같은 세트에서 비교한다.
3. **같은 공간 다컷의 시각 근거.** 장소 레퍼런스가 없으면 먼저 통과한 컷을 다음 컷의 환경 근거로 넘기는
   방식을 해나 사례로 비교한다(기준 §5가 검토 대상으로 둔 방식).
4. **재생성 경로.** 촬영 성립 결함이면 이미지 기획(촬영 설계)부터 다시 돌리고, 보정 문구에는 결함만 넘긴다.
5. **수정 starter A/B.** 작업 트리의 수정 지침을 저장해 같은 6캐릭터로 다시 생성하고, 시선·표정·컷 유형의
   분포와 자연스러움을 이 문서와 같은 방식으로 판정한다.

### 9.2 이미지 기획은 고정된 premise 안에서만 바꾸고, 촬영 수단은 고정 폰으로 수렴한다 (확인됨)

- 여섯 캐릭터 모두 `capture_style` 페르소나가 비어 있다(`capturePreferences: []`). 사진을 찍어 주는 동행도
  확립돼 있지 않다(유하의 민서는 "가끔 촬영을 도와준다" 정도). 촬영 성립을 설명해야 하므로
  "가구 위 폰 셀프타이머/삼각대"가 기본값이 된다. 기획된 인물 컷 10개 중 7개가 이 방식이다.
  그 결과 대부분 1.5~2.3m 거리, 허리~눈높이, 인물 쪽을 정면으로 향한 고정 시점이다.
- 최근 시각 이력 비교는 이미지 기획에만 있다. premise가 이미 같으면 바꿀 수 있는 것이 자세·거리 정도다
  (나희: 거울 앞에 선 사진 → 앉아서 직접 찍힌 사진).

### 9.3 생성 단계가 레퍼런스 구도로 끌려간다 (관찰, 원인 미확정)

- 레퍼런스가 하나라도 있으면 `/images/edits`로 보낸다(`src/generation/providers/openai-image.provider.ts:89, 113`).
  10/8 잡 13개가 모두 edit 경로였다. 얼굴이 보이는 컷은 Image 1이 스튜디오 정면 포트레이트다.
- 유하 시험은 머리 각도·기울기·조명·머리 결이 얼굴 레퍼런스와 같고 입만 열렸다. 서린은 장소 레퍼런스 1장만 받아
  같은 소실점·배치를 냈다. 같은 프롬프트로 레퍼런스 구성만 바꾸는 비교 전에는 원인으로 확정하지 않는다.

### 9.4 재생성은 기획을 다시 하지 않는다 (확인됨)

- `regenerateShot`은 원래 잡의 `paramsJson`(레퍼런스, `_shot` 계획)과 프롬프트를 그대로 복사해 새 잡을 만든다
  (`src/drafts/drafts.repository.ts:602-612`, `src/drafts/drafts.service.ts:989`).
- 10/8 재생성 3건은 운영자가 검수 관찰을 프롬프트 끝에 붙인 것이다(코드에 없는 문구). 도건·나희는 구도가 그대로 나왔다.
  소이만 보정 문구가 시점을 직접 지정해서 바뀌었다.

### 9.5 고칠 곳 (우선순위)

1. post_plan에 최근 초안(게시·미게시·불합격 포함)의 premise·장소·행동·촬영 수단 요약을 넣는다. 게시글은 premise도 함께 넣는다.
2. post_plan 메모리 질의를 페르소나 고정문에서 분리한다. 최근 초안에 쓰인 메모리는 감점하고, 열린 사건은 한 번 쓰이면
   소비된 것으로 다룬다. natural-v1의 Canon 미기록 결정과 함께 검토해야 한다.
3. 기획 직후 구조적 중복 검사: 장소·행동·소품·촬영 수단을 최근 N건과 비교하고, 겹치면 겹친 항목을 인용해 한 번만 재기획한다.
4. 캐릭터별 `capture_style`(누가 찍는지, 자주 쓰는 방식)을 채운다. 데이터 작업이다.
5. 재생성에 "기획부터 다시" 선택지를 둔다. 구도·촬영 성립 문제는 이미지 기획부터 다시 돌린다.
6. 레퍼런스 구성 비교: 얼굴만 자른 레퍼런스, 이미지 순서, 장소 레퍼런스 유무를 한 요인씩 바꾼다.

1~3번 없이 지침만 바꿔 다시 생성하면 같은 입력에서 같은 구도가 나온다. 이번 시험이 그 사례다.

## 10. 이미지가 자연스럽게 나오지 않는 원인 (2026-10-12)

범위는 natural-v1의 10/8 배치와 10/11 시험이다. 10/8 기존 원인 분석
(`content-work/image-naturalness-root-cause-20261008/assessment.txt`)과 대조했다. 생성·LLM 호출은 하지 않았다.

새 Agent가 바꾼 것은 두 가지다. 이미지 기획이 레퍼런스 픽셀을 보고, 사진 검수 2단계가 추가됐다.
바꾸지 않은 것도 세 가지다. 기획이 장면을 짜는 방식, 생성에 들어가는 레퍼런스, 생성 호출 방식이다.
아래 원인은 모두 바꾸지 않은 쪽에 있다.

### 10.1 기획이 사진을 "증거를 배치한 장면"으로 설계한다 (확인)

- image_plan 계약의 `motionEvidence` 필드는 움직임의 근거를 화면에 넣게 한다. 이 값은 프롬프트 작성 입력으로 그대로 간다
  (`src/post-production/image-model-policy.ts:125`). 실제 출력 예는 다음과 같다.
  - 나희: "침대 위에 벗어 둔 다른 상의와 벤치의 외출 소품이 막 코디를 비교해 온 흐름을 뒷받침한다"
  - 서린: "막 넣으려다 남겨 둔 수건 모서리가 출발 직전의 준비 흐름을 만든다"
- 기획이 지정한 소품은 빠짐없이 그려진다(나희·소이·서린·도건 4컷 모두). 사건과 무관한 우연한 물건은 거의 없다.
  실제 스냅은 반대다. 촬영자가 무엇을 설명하려고 물건을 놓지 않는다.
- 저장된 v1 지침은 "clear action", "around the action"을 요구했다. 10/8 인물 사진 6장은 모두 손이 작업 중이다.
  후보 지침은 손동작을 빼게 했고, 그 결과 유하 시험은 차렷 자세가 됐다. 설명 동작과 정지 사이의 몸 상태
  (체중, 기댐, 무의식적인 손)를 기획할 방법이 없다.
- 공간도 "옷장 안에는 평소 입는 옷들이 정돈되어 걸려 있다"처럼 정돈된 상태로 기술된다.

### 10.2 생성 재료가 스튜디오형 이미지이고, 원본 전체가 전달된다 (관찰, 기여도 미확정)

- 배정된 레퍼런스 20장 중 인물 레퍼런스는 모두 회색 스튜디오 배경, 균일 조명, 보정된 피부, 정면 자세다.
  장소 레퍼런스는 사람 없는 정돈된 렌더 인테리어다. media 플래그상 12장이 AI 생성이다.
- 레퍼런스가 하나라도 있으면 원본 전체가 `/images/edits`로 간다. "얼굴만 쓰고 조명·표정은 버려라"는 텍스트로만
  전달된다(`src/generation/providers/openai-image.provider.ts:89, 113`).
- 얼굴이 보이는 생성 8장은 모두 레퍼런스와 같은 화보형 얼굴(피부 결, 화장, 입술 광택)로 나왔다. 유하는 입 모양과
  머리핀 위치까지 같다. 얼굴이 없는 해나 2컷째가 가장 폰 사진에 가깝다. 비교 이미지는 `faces-ref-vs-gen.jpg`.
- 이 자료로는 모델 자체의 미화 경향과 레퍼런스 영향을 분리할 수 없다.

### 10.3 프롬프트가 폰 사진의 조건 대신 잘 나온 사진의 조건을 적는다 (확인 + 관찰)

- 인물 컷 프롬프트 8개 중 6개에 "중간 초점거리", "광각 왜곡 없이", "배경은 흐리게" 같은 전문 촬영 조건이 들어 있다.
  스마트폰 메인 카메라(광각, 깊은 심도)와 반대 조건이다. 이 문장이 없는 2개(해나)는 "문틈 자연광과 현관 실내등이 섞인
  평범한 혼합 조명"을 적었고, 결과도 가장 폰 사진에 가깝다.
- 프롬프트 작성 단계가 기획에 없던 "editorial"을 붙였다(유하 시험).
- 해나 프롬프트는 짧고 얼굴 비중도 달라서, 인과는 확정하지 않는다.

### 10.4 고쳐지지 않는 이유 (확인)

자연스러움 검수는 알려진 결함을 대부분 통과시킨다(§4, §8). 재생성은 같은 계획·레퍼런스·프롬프트를 복사한다(§9.4).
결함이 생겨도 위 원인으로 되돌아가는 경로가 없다.

## 11. 캐릭터 체형 기준과 레퍼런스 조명 개선 추가 (2026-10-12)

운영자 요청: 캐릭터 레퍼런스로 신체 비율 등 외형 리뷰 기준을 세우고,
강한 스튜디오 조명이 인물에 남아 배경 조명과 어긋나는 문제를 개선 계획에 추가한다.
상세 근거는 [캐릭터 레퍼런스 신체 비율·외형·조명 리뷰](character-reference-body-lighting-review-2026-10-12.md)에 있다.

현재 개발 서버의 활성 인물 사진 35장(6명)을 직접 확인했다. ID·순서·URL과
현재 S3 원본 SHA-256도 보관본과 모두 일치했다. 이번에는 생성·캐릭터 수정·
레퍼런스 교체·자동 검수 변경을 실행하지 않았다.

### 11.1 신체 기준과 자료 한계

| 캐릭터 | 유지할 비율·윤곽 | 이번 자료로 확정하지 않을 것 |
| --- | --- | --- |
| 한소이 | 좁은 어깨, 가는 팔다리, 완만한 허리·골반 관계 | 니트 얼굴 자료의 하체, 바지 안의 골반 상세 |
| 권도건 | 넓은 어깨와 강한 전완·허벅지·종아리의 균형 | 가려진 둔근·복부, 사진으로 잰 181cm |
| 서린 | 볼륨 있는 상체, 허리·둥근 골반·다리의 연결 | 가려진 얼굴과 등신, 레깅스 허리선에 의한 다리 실측 |
| 유하 | 상체·허리 굴곡, 골반·허벅지의 부드러운 연결 | 반바지의 폭을 실제 골반 폭으로 해석한 값 |
| 나희 | 상체 볼륨과 허리·골반·허벅지의 균형 | 굽·드레스가 포함된 사진의 7.5등신·맨발 키 |
| 해나 | 과장되지 않은 어깨·팔 운동 윤곽과 좁은 허리 | 넉넉한 바지 안의 하체, 수축한 팔의 기본 두께 |

등신·허리·다리 길이를 공통 숫자에 맞추지 않는다. 자세·원근·의복을 먼저
고려하고 같은 캐릭터의 비교 가능한 부위에서만 체형 변화를 판정한다.
머리·관절·윤곽이 안 보이면 미평가로 남긴다. 정량 허용 오차는 아직 검증하지 않았다.

### 11.2 조명 개선 우선순위

**인물·배경의 빛이 분리되면 정체성이 맞아도 자연스러움은 불합격**이다.
밝기 자체보다 광원 방향·그림자 부드러움·주변 반사색·노출·질감의 관계를 본다.
등록 자료 전체가 회색 스튜디오인 것은 아니다. 한소이 얼굴은 녹색 배경이고
해나 몸은 체육관이지만 원본의 정면광과 보정 표현을 새 장소에 고정하는 위험은 같다.

1. 얼굴·중립 전신과 표정·패션·수축 근육 보조를 역할에 맞게 고른다.
   기존 설명에도 조명 복제 제외가 있으므로 금지 문구 추가만으로 완료하지 않는다.
2. 이미지 기획에서 현재 장소·시간의 광원이 인물·옷·접촉면에도 작용하도록 정한다.
   프롬프트 작성자가 기획 밖의 beauty lighting·editorial을 추가하는지도 대조한다.
3. 같은 정체성·구도·의복을 유지한 조명 완화 후보를 별도 버전으로 비교한다.
   얼굴 크롭·참조 순서 변경은 별도 실험이다. 단순 어둡게 하기나 배경 제거를
   조명 개선으로 간주하지 않는다.
4. 유하·해나 × 창 측광 낮/따뜻한 실내 밤 × 원본/조명 완화 후보 × 2회,
   16장 비교를 후보로 둔다. 다른 입력은 고정하고 지정한 참조 한 장만 교체한다.
   후보 자체의 정체성·체형이 달라지면 유효 비교에서 제외한다. 현재 미실행이다.
5. 조명·질감 통합 개선과 얼굴·체형 보존을 각각 확인한 뒤 6명으로 확대한다.
   의도된 화보의 스튜디오 조명은 허용한다. 조명의 자연스러운 변화가 얼굴 정체성
   오류로 거절되거나 체형·패션 매력을 줄이는 회귀가 없는지도 확인한다.

레퍼런스 조명 잔존은 관찰과 사용자 피드백으로 확인된 개선 대상이다.
레퍼런스·모델·촬영 문구 각각의 기여도와 조명 완화 효과는 통제 비교 전까지
미확정이며, 이 계획의 추가를 실제 이미지 개선 완료로 보고하지 않는다.

### 11.3 전신 비율 재평가 반영 (2026-10-13)

나희의 덩치, 해나의 덩치·팔 길이는 운영자 기준상 불합격으로 정정한다.
전신·체형 원본 13장의 재검토 근거는 상세 리뷰 §7에 기록했다.
앞선 참조 적합성 합격을 현재 전신 실루엣의 승인으로 사용하지 않는다.

- 우선 수정 대상: 나희 20·30의 전체 체격, 해나 40·60의 덩치·팔 길이.
- 추가 검토: 한소이 90, 유하 20의 큰 머리 비중과 몸·다리 관계. 즉시 불합격은 아니다.
- 권도건은 운동선수 체격의 균형이 유지된다. 서린은 보이는 신체 연결이 대체로 성립하지만 머리 비율은 미평가다.
- 체형 수정 후보와 조명 수정 후보는 효과를 구분해 검수한다. 조명 완화만으로 나희·해나의 체형 문제가 해결됐다고 보지 않는다.

이번에는 문서의 판정과 개선 우선순위만 정정했으며 레퍼런스 제작·교체는 하지 않았다.

### 11.4 수정 필수 레퍼런스 교체 완료 (2026-10-13)

후속 사용자 요청으로 나희 20·30, 해나 40·60의 4장을 재생성·검수해 개발 서버의 활성 참조로 교체했다. 기존 원본은 비활성으로 보존했고 새 설명·검색 색인을 저장했다. 새 조회에서 활성 순서·원본 해시 및 Canon·다른 참조 보존을 검증했다. [상세 교체 기록](character-reference-replacement-2026-10-13.md)을 현재 버전의 근거로 삼는다.

11.3의 덩치·팔 길이 불합격은 이전 원본에 대한 판정이다. 현재 활성 참조의 체형 수정은 완료했으며, 신규 게시물 장면에서의 조명 통합과 생성 회귀 비교는 별도 미검증 항목으로 유지한다.

### 11.5 전체 캐릭터 재판정·보정 확대 (2026-10-13)

후속 요청으로 체형 수정 4장 외의 자료도 다시 판단했다. 한소이·유하 전신의 머리와 몸 관계를 소폭 조정하고, 6명 전체에서 추가 21장의 얼굴·전신 조명 보정과 직접 검수를 완료했다. 서린 120의 주변광 자료와 기존 나희·해나 체형 수정 4장은 유지한다. 서린의 스포츠브라 자료 9장은 상의 변경 선택을 기다린다.

새 21장의 개발 서버 업로드는 자동 승인 검토가 기존 승인의 4장 범위를 넘는다는 이유로 거절해, 확대 전송·교체 승인을 요청했다. 아직 추가 21장이 활성 참조로 교체된 상태는 아니다. 캐릭터별 근거와 전후 비교, 생성 필터 차단의 실제 범위는 [전체 재판정·추가 보정 기록](character-reference-completion-2026-10-13.md)에 있다. 레퍼런스 보정 자체와 새 SNS 장면에서의 배경 조명 통합 개선은 별도로 검증한다.
