# 핵심 시각 선택과 최소 촬영 지시

2026-10-16 사용자 승인 범위: 자체 점검을 제거한 새 Agent를 기준으로 게시물 기획,
이미지 기획, 프롬프트 작성의 역할을 유지하면서 불필요한 촬영 지시를 줄인다.

- 게시물 기획은 캐릭터 맥락과 최근 게시물에서 올릴 법한 소재·순간을 선택한다.
  단순한 셀카·착장도 가능하며 선택 이유를 증명할 사건·소품·동작을 만들지 않는다.
- 이미지 기획은 사진의 초점·매력을 결정하는 선택과 명시적 필수 조건을 남긴다.
  부수적인 손 위치·관절·배경 배치는 열어 두고 빈 필드를 억지로 채우지 않는다.
- 프롬프트 작성은 선택된 관계를 보존하며 중복 필드를 연결된 문장으로 통합한다.
  고정 섹션 목록과 최소 길이는 요구하지 않고 새 연출이나 자체 점검을 추가하지 않는다.
- `negativePrompt`는 공급된 모델 정책을 따른다. 해당 컷의 필요한 제외만 표현하고
  일반적인 품질·해부학·AI 흔적 체크리스트나 중복 제외를 추가하지 않는다.
- 캐릭터 설정, 모델, 출력 schema, 참조·입력 충돌 계약, 캡션, 독립 사진 검수는 유지한다.

소유자는 `prompts/structured-planning.ts`이며 실행은 저장된
`postAgent.natural-v1` 번들을 사용한다. 소스 변경만으로 실행 설정은 바뀌지 않는다.
기존 `GenerationSettingsService.saveNaturalAgentBundle`의 revision 비교로 저장하고
재조회한다. 새 초안에 적용하며 이전 초안의 설정 스냅샷은 변경하지 않는다.

개발 서버 점검 시 Qwen 정책은 `qwen-image-3-policy-v1`으로 `negativePrompt=null`을
요구했고 공통 네거티브 설정은 없었다. provider는 비어 있지 않은 별도 값의 전달을
지원하지만 현재 Agent 정책은 생성하지 않는다. 로컬의 미커밋 v2 공통 네거티브 기능은
이 변경의 배포 범위가 아니다. 제외 조건은 현재 정책에 따라 본문에 간결하게 보존한다.

검증은 변경 지침·schema 및 보존 단계 대조, 기존 parser/runner/provider 테스트,
빌드, 배포 후 코드 지문·건강 상태·설정 재조회로 한다. 실제 이미지 품질은 이 검사만으로
보증하지 않는다. 사용자 확정 합격·불합격 표본을 기준으로 별도 생성 비교가 필요하며,
검수 LLM의 합격이나 한 장의 성공을 품질 개선 완료로 취급하지 않는다.
