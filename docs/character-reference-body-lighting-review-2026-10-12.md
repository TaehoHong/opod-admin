# 캐릭터 레퍼런스 신체 비율·외형·조명 리뷰 — 2026-10-12

현재 레퍼런스는 인물 식별과 체형 비교에 유용하지만, 모든 캐릭터의 신체 비율을 합격시킨 것은 아니다. **10/13 재평가에서 나희의 덩치, 해나의 덩치·팔 길이를 사용자 기준상 불합격으로 정정했다(§7).** 원본의 스튜디오 빛과 보정된 표현까지 새 장면에 유지하면 인물과 배경이 분리되므로 체형과 장면의 빛도 각각 검수해야 한다. 아래는 사진에서 확인한 기준과 개선 제안이며, 캐릭터 설정·레퍼런스·자동 검수 지침을 변경한 결과가 아니다.

공통 판정 원칙은 [게시물 이미지 평가 기준](image-evaluation-criteria.md), 실행 개선 계획은 [기존 이미지 리뷰 §11](natural-agent-image-review-2026-10-11.md#11-캐릭터-체형-기준과-레퍼런스-조명-개선-추가-2026-10-12)에 연결한다.

## 1. 근거와 한계

- 개발 서버의 `VisualProfileService.getProfile`로 6명의 현재 비주얼 프로필·활성 목록을 읽었다. 활성 인물 레퍼런스는 한소이 8, 권도건 4, 서린 11, 유하 3, 나희 3, 해나 6장, 총 35장이다.
- 현재 ID·순서·URL은 10/1 보관본과 일치했다. 현재 S3 원본 35장의 SHA-256도 검수에 사용한 로컬 원본과 모두 일치했다. 설명은 현재 프로필을 사용했다. 과거 캡션을 현재 설명으로 간주하지 않았다.
- 35장 전체를 캐릭터별 비교 시트로 직접 봤다. 중립 전신 6장, 권도건 상의 탈의 전신, 나희 얼굴, 해나 팔을 든 체형 사진, 권도건·유하 얼굴 등 11장은 원본으로 추가 확인했다.
- 비활성 사진 6장, 장소 레퍼런스 전체, 신규 생성 결과는 이번 평가 대상이 아니다. 기존 얼굴 비교 시트는 조명·표정 잔존의 보조 자료로만 확인했다. 기존 리뷰와 참조를 먼저 읽었으므로 생성 결과의 블라인드 재평가가 아니다.
- 키·가슴/허리/골반 둘레·체지방·렌즈·광원 출력은 사진만으로 확정하지 않는다. 둘레와 사진의 가로 폭도 서로 다른 값이다. 아래 체형 기준은 보이는 윤곽과 부위 간 관계에 대한 비교 기준이다.

증거 묶음: `../../content-work/character-reference-review-20261012/`의 `current-profiles.json`, `current-image-hashes.json`, `reference-manifest.json`, `character-0-contact.jpg`~`character-5-contact.jpg`. 원본 경로와 전체 mediaId는 manifest에 있다. 조회는 읽기 전용이며 생성·게시·DB 변경을 하지 않았다.

## 3. 생성 결과에 적용할 신체 비율 리뷰 기준

모든 캐릭터를 같은 등신·허리·다리 길이로 맞추지 않는다. 먼저 캐릭터별 중립 참조를 고르고, 결과의 자세·시점·의복 때문에 생긴 차이를 설명한 뒤 남는 체형 변화만 판단한다.

정량 기준이 필요해지면 동일한 카메라 높이·거리, 중립 정면·측면, 머리와 발이 보이는 자료에서 랜드마크와 오차를 기록한다. 머리 높이에 헤어 볼륨을 포함하는지, 발 바닥에 신발 굽을 포함하는지 먼저 정해야 한다. 이번에는 랜드마크 실측과 허용 오차 검증을 하지 않았으므로 임의의 ±비율·등신 합격선을 만들지 않았다.

현재 나희의 7.5등신 설정과 사진을 수치로 바로 일치시켰다고 보지 않는다. 한소이의 작은 체구도 머리를 과도하게 키우거나 팔다리를 줄이는 지시로 번역하지 않는다. 신체 기준은 검수용이고 매 프롬프트에 전부 열거하는 외형 목록이 아니다.

## 4. 스튜디오 조명 문제 리뷰

운영자 피드백은 **스튜디오 조명이 강하게 남아 배경과 인물의 빛이 맞지 않는 결과는 불합격**이라는 기준으로 반영한다. 광원의 실제 출력·노출값은 미확인이다. 보이는 문제는 강한 정면 보충광, 균일한 얼굴 밝기와 피부 하이라이트, 약한 음영 변화가 새 장소에도 유지될 위험이다.

등록 자료 전부가 회색 배경인 것은 아니다. 한소이는 녹색 포트레이트가 대부분이고 해나 체형은 체육관이다. 배경 종류와 별개로 원본의 얼굴 빛·표정·자세가 불필요하게 유지되는지가 핵심이다.

얼굴 참조와 기존 생성 얼굴 비교 시트에서는 유하의 미소·고개 각도·밝은 피부 표현이 이어지는 인상이 보인다. 이 관찰과 사용자 피드백은 개선 필요성의 근거다. 조명의 원인이 레퍼런스인지 모델의 미화 경향인지, 기획·프롬프트가 추가한 촬영 조건인지까지는 통제 비교 없이 확정하지 않는다.

### 결과 사진의 조명 합격 기준

1. 장면에서 확립된 주광원 방향과 인물의 코·턱·머리·옷·바닥 그림자가 양립한다. 카메라 밖 광원도 기획에 확립됐다면 허용한다.
2. 광원 크기·거리에 따른 그림자 부드러움이 성립한다. 얼굴만 원본의 균일한 보충광에 남아 있지 않은지 본다.
3. 피부·머리·옷에 장소의 색과 주변 반사광이 작용한다. 바탕 피부색은 유지하되 모든 장소에서 동일한 RGB·화이트밸런스를 요구하지 않는다.
4. 인물 밝기와 공간 밝기의 관계가 노출·광원 위치로 설명된다. 밝은 얼굴 자체는 실패가 아니지만 근거 없는 별도 스튜디오광으로 공간에서 분리되면 실패다.
5. 발·좌석·소품 접촉과 그림자, 초점·질감도 같은 촬영으로 읽힌다. 빛만 맞추고 인물 질감이 별도 보정본처럼 남으면 전체 통합을 다시 판단한다.

관찰 기록은 부위·방향·밝기 관계를 적는다. 예: “창은 화면 오른쪽인데 볼과 코의 밝은 면은 원본 정면광처럼 양쪽에 유지되고, 창 반대쪽 목·옷에도 비슷한 밝기가 남아 인물의 빛이 공간에서 분리된다.” 이는 예시이며 이번에 새 생성 결과에서 확인한 사실로 기록하지 않는다.

조명 완화 후보는 미제작이다. 단순 노출 하향·배경 제거·흐림은 원본의 빛 방향과 반사 형태를 지우지 못하고 얼굴·체형 근거를 약하게 만들 수 있어 기본 처방으로 채택하지 않는다. 전문 화보·협찬 촬영에서는 기획된 스튜디오 조명을 사용할 수 있다.

통제 비교 후보는 유하·해나부터, 창 측광 낮 장면과 따뜻한 실내 밤 장면 각각에서 원본(A)과 조명 완화 후보(B)를 비교하는 것이다. 조건별 2회면 2명 × 2장면 × 2조건 × 2회 = 16장이다. 장면·모델·프롬프트·참조 순서·얼굴/몸 역할은 고정하고 지정한 참조 한 장만 교체한다. 모델에 없는 참조 강도 옵션을 가정하지 않는다. 이번 요청에서는 생성하지 않았다.

채택하려면 인물·배경의 빛 통합이 개선되면서 얼굴·체형·의도된 매력은 유지돼야 한다. 원본 스튜디오 컷에서는 회귀가 없는지도 확인하고, 이후 6명의 서로 다른 장면으로 확대한다. 잘 나온 한 장만으로 일반 효과를 확정하지 않는다.

## 6. 기록 상태

현재 사진·설명·활성 목록과 바이트 일치는 확인된 자료다. “배경과 어긋나는 스튜디오 조명 잔존은 불합격”은 사용자 품질 피드백이며 기존 전체 통합 기준과도 일치한다. 캐릭터별 비교 기준은 근거 범위와 함께 문서화했다. 조명 완화 후보의 효과, 새 정량 허용 오차, 모델 원인과 자동 검수 개선 효과는 미검증 제안으로 남긴다.

문서·증거 묶음만 작성했고 앱 코드, DB·S3 원본, 프롬프트, 배포 상태를 바꾸지 않았다. 소유 모듈·검증 명령이 바뀌지 않아 codebase guide 수정은 필요하지 않다.

| 서린 10·50·130 | 보이는 신체 비율 대체로 합격, 머리 비율 미평가 | 정면 10과 티셔츠 130의 몸통·골반·팔다리 연결은 무리 없이 읽힌다. 측면 50은 허리 굴곡과 가슴·둔부 돌출이 강해 포즈까지 기본 체형으로 고정하지 않아야 한다. 상체 볼륨은 설정과 양립하고 덩치 전체가 큰 인상은 두드러지지 않는다. 정면의 머리가 잘려 등신 합격은 판단하지 않는다. |

우선순위는 해나의 덩치·팔 길이와 나희의 전체 몸 크기다. 나희는 상체 볼륨이라는 정체성과 전체 체격을 분리해 조정하고, 해나는 운동한 윤곽을 유지하면서 어깨·팔의 두께와 길이를 검토한다. 단순히 전신을 가로로 압축하거나 손끝만 올리는 방식은 다른 비율을 깨뜨릴 수 있다. 한소이·유하는 머리와 몸의 관계를 후보 비교에서 추가 검토하되, 도건·서린을 같은 방향으로 일괄 축소하지 않는다.

운영자가 확정한 불합격 항목과 그 밖의 시각적 재검토 의견은 구분했다. 수정 후보 제작·교체·DB 변경은 실행하지 않았다.

## 8. 수정 필수 레퍼런스 교체 완료 — 2026-10-13

§7 이후 사용자가 재생성과 교체를 요청해 나희 20·30과 해나 40·60을 새 버전으로 교체했다. 나희는 전체 체격, 해나는 덩치·팔 길이를 조정하고 두 캐릭터의 조명도 완화했다. 기존 4장은 비활성으로 보존했으며 얼굴 레퍼런스와 다른 캐릭터 자료는 유지했다. 새 설명·검색 색인 저장과 활성 순서·S3 원본 해시를 교체 후 조회로 검증했다.

§2·§7의 불합격은 기존 mediaId에 대한 역사적 판정이다. 현재 활성 버전의 ID·검수·검증과 전후 비교는 [레퍼런스 재생성·교체 기록](character-reference-replacement-2026-10-13.md)에 있다. 새 기준 사진의 검수 통과를 모든 SNS 장면의 조명 문제 해결로 일반화하지 않는다.

## 9. 전체 캐릭터 재판정과 추가 보정 — 2026-10-13

사용자가 다른 캐릭터도 다시 판단해 수정하도록 요청해, 체격 불합격 4장만 교체했던 범위를 확대했다. 한소이 90과 유하 20·30의 머리·몸 관계를 소폭 조정했고, 다른 캐릭터의 얼굴·전신 조명도 보정했다. 추가 보정·검수 완료는 한소이 8장, 도건 4장, 서린 1장, 유하 3장, 나희 1장, 해나 4장으로 총 21장이다. 기존 나희·해나의 체형 수정 4장과 실제 주변광이 있는 서린 120은 유지한다.

서린의 스포츠브라 사진 9장은 상의 변경 선택을 기다린다. 출력 필터 차단을 실제 확인한 것은 서린 10의 두 번의 보정 요청이며, 9장 전체를 시도해 차단된 것은 아니다. 서린 130의 티셔츠 보정은 완료했다.

추가 21장은 아직 서버에 반영하지 않았다. 자동 승인 검토가 기존 4장 승인은 확대 전송을 포함하지 않는다는 이유로 업로드를 거절해, 추가 사진·참조 메타데이터의 개발 서버 업로드·교체 승인을 요청했다. [전체 재판정·추가 보정 기록](character-reference-completion-2026-10-13.md)에 캐릭터별 문제·수정·유지 사유와 전후 비교, 대기 항목을 기록했다.
