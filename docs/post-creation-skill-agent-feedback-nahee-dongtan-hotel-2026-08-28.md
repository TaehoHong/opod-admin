## 부정 평가와 원인

1. 초기 결과가 나희의 핵심 태도보다 우아함을 앞세움.
   - 원인: 호텔과 고급스러움 레퍼런스가 페르소나 기반 섹스어필 레퍼런스보다 강하게 반영됨.
2. 초기 이미지가 자연스러운 개인 사진보다 화보처럼 보임.
   - 원인: 정돈된 조명, 중앙 구도, 완성된 모델 포즈가 반복됨.
3. 최초 동탄룩 해석이 검정 오프숄더 상의와 아이보리 미니스커트 투피스였음.
   - 원인: 용어의 대표적인 온라인 실루엣을 충분히 조사하지 않고 일반적인 데이트룩으로 해석함.
4. 일부 이미지의 손 품질이 낮았음.
   - 원인: 손이 커튼, 휴대폰, 창틀과 상호작용하는 복잡한 자세에서 손 구조 검수가 부족했음.
5. 첫 캡션이 실제 개인 게시물보다 제작된 문구처럼 들림.
   - 원인: 이미지 평가와 팔로워 선택 유도 문장이 들어가 일상 근황형 리듬이 사라짐.

## 최종 승인 기준

- 딥 버건디의 불투명한 밀착 미디 원피스가 세 장에서 일관됨.
- 나희의 얼굴, 체리브라운 헤어, 글래머 체형과 직접 시선이 유지됨.
- 정면, 창가 기대기, 측면 돌아보기로 구도가 변주됨.
- 손과 발, 의상 슬릿, 창문·커튼 접촉이 시각적으로 자연스러움.
- 모든 파일이 1080×1350의 4:5 규격임.
- 캡션은 짧은 일상 근황형 한 문장이고 해시태그가 없음.

## Skill 반영 후보

1. 캐릭터의 핵심 콘텐츠 태도를 보조 무드보다 먼저 잠그고, 후보 공개 전 해당 태도가 사진에서 읽히는지 검사한다.
2. 밈·신조어 기반 의상은 생성 전에 실제 소셜 용례와 대표 실루엣을 조사하며, 지역 주민의 현실을 일반화하지 않는다.
3. 사용자가 `모든 사진에 적용`이라고 지정한 체형·손·색보정 지시는 shot이 아니라 post 범위의 잠금 필드로 승격한다.
4. 자연스러운 소셜 사진 요청에서는 정면 모델 포즈뿐 아니라 이동 중, 커튼 정리, 거울 셀피 같은 일상 동작을 포함한다.
5. 캡션이 인공적이라는 피드백을 받으면 실제 개인 계정 캡션을 다시 조사하고, 설명·광고·참여 유도 문장을 우선 제거한다.
6. 안전 정책 거절을 다른 공급자로 우회하지 않으며, 반복 거절된 구도는 실패 사실과 가장 가까운 안전 대안을 구분해 기록한다.

## Agent 기억·행동 개선 후보

- `나희 / character / active`: 우아함만으로는 부족하며 자신이 화면을 통제하는 성인 패션 섹스어필이 핵심.
- `나희 / character / active`: 글래머 체형과 직접 시선을 이미지 세트 전체에서 일관되게 유지.
- `공통 / global / active`: 직접 레퍼런스 부족 시 페르소나 특성을 표현하는 성인 크리에이터의 소셜 포즈·시선·카메라 태도를 조사.
- `캡션 / global / example_only`: 이번 게시물에서는 한 문장 근황형 캡션과 서로 다른 색의 하트 3개가 승인됨. 다른 캐릭터나 게시물의 고정 규칙으로 일반화하지 않음.

## 회귀 평가 시나리오

1. 호텔 배경의 나희 게시물을 만들 때 결과가 우아한 드레스 화보로만 나오는지 확인한다.
2. `동탄룩` 요청에 투피스나 일반 미니드레스를 제안하지 않고, 조사 후 대표적인 밀착 단색 원피스 실루엣을 사용하는지 확인한다.
3. `손 개선과 체형 변경을 모든 사진에 적용` 요청이 일부 후보에만 반영되지 않는지 확인한다.
4. `자연스럽게` 요청에 중앙 정렬, 완벽한 조명, 반복된 정면 모델 포즈가 다시 나타나지 않는지 확인한다.
5. 짧은 Instagram 캡션 요청에 이미지 설명, 추상적 감상, 팔로워 선택 유도 문장이 추가되지 않는지 확인한다.
6. 사용자가 캡션 이모지를 단계적으로 수정할 때 마지막 지시만 반영하고 제거된 이모지를 되살리지 않는지 확인한다.
