# 기존 Agent 소스 보관

UI의 `기존 Agent` (`existing` 및 Agent 식별자가 없는 과거 초안)만 보관한다. `natural-v1`은 활성 상태를 유지한다. 데이터베이스 행과 과거 실행 기록은 삭제하거나 변환하지 않는다.

`source/`에는 변경 전 파일 원문을 저장했다. 혼합 파일은 새 Agent가 쓰는 구현도 포함하므로 통째로 복구하면 현재 기능을 덮어쓸 수 있다. `manifest.json`의 원래 경로와 SHA-256으로 원문을 확인하고 필요한 기존 Agent 구현만 검토해 복구한다. 프런트엔드 일부 파일은 작업 시작 당시 이미 수정된 상태였으며 그 시점의 원문을 보관했다. 비밀 설정 파일·환경 파일·DB 덤프는 포함하지 않는다.

`.snapshot` 확장자는 실행할 수 있는 소스가 아니다. archive는 TypeScript include(src/prompts/test), ESLint/Prettier 스크립트 대상, Vite 소스 바깥에 있고 Jest의 `.spec.ts` 패턴에도 해당하지 않는다. 별도 빌드 설정 변경 없이 컴파일·테스트·실행에서 제외된다.

활성 코드에서는 기존 초안의 생성·수동 수정·단계 실행·자동 집계·게시·이미지 잡 실행을 막는다. 기존 전용 DraftWorker의 기획 및 프롬프트 작성 orchestration은 제거했다. 새 Agent와 이미지 생성 위저드가 사용하는 planner/parser/이미지 생성 공통 구현은 남긴다. 새로운 초안은 활성 Agent를 명시적으로 선택해야 하며 기존 Agent로 fallback하지 않는다. 스케줄러도 명시적 새 Agent concept이 없으면 초안을 만들지 않는다.


기존 전용 기획·프롬프트 작성·암묵적 기존 초안 생성·기존 DB 지침 실행 테스트는 원문 snapshot에 보관하고 활성 suite에서 제거했다. 공유 runner/parser·초안 편집·게시·스케줄러 테스트는 명시적 natural 설정과 현재 이미지에 맞는 검수 증거를 사용하는 fixture로 유지한다. 사진 검수 gate 회귀는 보존한다. HTTP 세대별 쓰기 차단과 과거 읽기, 독립 이미지 생성의 허용은 별도 archival 계약 테스트로 검증한다.

DB E2E 파일은 보관된 Agent의 생성·변경 거부 및 이력 조회 계약으로 갱신했다. 이 작업에서는 DB E2E를 실행하지 않았다. 전체 TypeScript 검사로 E2E 소스의 형식만 확인했다.

기존 또는 식별자가 없는 초안 상세는 `ArchivedAgentWorkView`의 읽기 전용 기록 화면으로 연다. 저장된 캡션·생성 이미지·프롬프트·산출물과 원본 실행 기록을 조회하며, 자동 진행·편집·재생성·게시 컨트롤은 제공하지 않는다. 자연형·레퍼런스 Agent 화면은 기존 분기를 유지한다.
